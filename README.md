## Development
This project was developed during a game development class in a team of four people.

As the programmer and story writer, I was responsible for implementing gameplay mechanics and developing the narrative/dialogue of the game.

- Wrote the game's narrative and dialogue.
- Designed and implemented the branching narrative.
- Developed custom HTML and CSS elements.
- Used JavaScript to implement additional interactions
  and functionality.
- Integrated the complete experience into Twine.

## Technical Details

- Engine/Tool: Twine
- Languages: HTML, CSS, JavaScript
- Development type: [Individual / Team project]
